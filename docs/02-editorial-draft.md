## 1. トップページに載せる文章

### VOCAL LISTENING LAB

**声を聴く。違いをつかむ。自分の歌に持ち帰る。**

好きな歌の、どこに心が動いたのだろう。

声の色、言葉を置くタイミング、ふっと消える語尾、重なり合うコーラス。歌の魅力は、一つずつ耳を向けると、少しずつ具体的になる。

この教材では、ソウル、ジャズ、ファンク、ロック、R&B、日本語の歌を、14のテーマで聴き比べます。1回15分から。気になった表現は、短い言葉やフレーズで試してみましょう。聴くだけの日も、ちゃんと一歩です。

**ボタン：**「最初のレッスンへ」「続きから」「テーマで選ぶ」

補足：「14回は、自分のペースで進められます。楽譜が読めなくても、専門の機材がなくても始められます。」

## 2. 毎回共通の掲載文案

### 一曲、三つの聴き方

1. **全体を受け取る。** まずは好きに聴く。声が近い、言葉が跳ねる、途中で景色が変わる。最初の印象を一つ残す。
2. **今日の一点を追う。** 声の入り、母音、語尾など、その回の問いだけに注目する。全部を同時に分析しなくていい。
3. **伴奏の中へ戻す。** 見つけた表現は、ドラム、ベース、コーラスの中で何をしているだろう。全体の印象とつなげる。

### 聴いたことを言葉にする

「うまい」「エモい」の先を、一つだけ書いてみよう。たとえば、「最初は短く切っていた語尾を、最後だけ長く残した」。聞こえた場所と変化があれば、それで十分です。

### 自分の声で試すとき

出しやすい高さと無理のない音量で、短く試しましょう。原曲のキーや声量に合わせる必要はありません。痛み、声がれ、出しづらさを感じたら歌うのをやめ、今日は聴く課題に切り替えてください。症状が続く・繰り返す場合は耳鼻咽喉科などへ相談してください。[S1]

### この解説について

ここにある分析は、録音を聴くための観点です。歌手の意図や発声の仕組みを、完成した音だけから決めつけるものではありません。違う聞こえ方をしたら、その場所をメモして聴き直してみましょう。

### 版の照合で特に注意する曲

- Sam CookeとRay Charles：後年のライブ・再録・再発年をオリジナルと混同しない。
- Billie Holiday：同名曲の年代・共演者・テイクを照合する。1941年版が用意できない場合は教材側の対象を正式に変更する。
- James Brown：同名曲の別録音を区別する。
- Michael Jackson：アルバム／シングル／後年のミックス違いを聴きどころの前提に混ぜない。
- Rufus & Chaka Khan：ライブを含むアルバムだが、対象の曲自体はスタジオ録音。曲単位で判定する。
- Boyz II Men：初出、後から収録された版、編集の長さを確認する。
- 宇多田ヒカル：オリジナルの演奏を使う。再マスター年や同名ライブを別項目にする。[S8]
- 山下達郎／MISIA：シングル版とアルバム版を確認する。カタログにあるから同一録音、と即断しない。
- 全曲：日本での配信可否と公式リンクを確認する。代替は同じ教育目的を満たすものから選び、差し替え履歴を残す。

## 4. 全14レッスンの導入・問い・課題

### Lesson 01｜声の輪郭をつかむ

**リード：**「好きな声」を、もう一段具体的に。

**導入本文：** 歌い手を覚える入口は、声の印象でいい。温かい、澄んでいる、近くで話しているみたい。その印象が生まれた場所を、一つだけ探してみよう。音の始まり、伸びる母音、最後に消える瞬間。同じ声でも、時間の中では表情が動いている。

今日はSam Cooke、Carpenters、Norah Jonesを比較する。「誰が一番よい声か」ではなく、自分がどの変化に耳を引かれたかを見つける。声の特徴と、録音の近さをひとまず分けて考えるのも、よい出発点になる。

**到達点：** 一つのフレーズの始まり・途中・終わりを区別して説明する。

**問い：** 最初の印象を作っていたのは、どの部分だった？

**任意の実験：** 自分で作った短い言葉を、普段の声で二通り言う。最後を短く切る／少し長く残す。高さや大きさをできるだけそろえて比べる。

**声を出さない課題：** 指でフレーズの長さをなぞり、終わりの形を「切れる／薄くなる／次へ続く」でメモする。

**回答例：**「柔らかいと感じた理由を、音の入りか語尾かに分けて探した。語尾に注目すると、最初の印象が変わった。」実際に選んだ曲と場面を追記する。

### Lesson 02｜言葉は拍のどこに着く？

**リード：** メロディーを追いながら、言葉の足取りを聴く。

**導入本文：** 言葉の最初の子音と、音の高さがよく聞こえる母音は、必ずしも同じ瞬間に始まらない。歌を拍の前・後ろで説明するときは、何を目印にしているかを決めよう。伴奏の拍、言葉の輪郭、フレーズの着地点を別々に追うと、歌の動きが見つけやすい。

Billie Holiday、Frank Sinatra、Ella FitzgeraldとLouis Armstrongを聴く。雰囲気で「遅らせている」と覚える前に、一つの言葉と伴奏の関係を観察してみよう。

**到達点：** 子音の入りと母音の中心を混同せず、拍との関係を述べる。

**問い：** ゆったり感じる場面でも、言葉の終わりはどこへ着いている？

**任意の実験：** 4拍を数えながら「今日はいい日」を話す。言い始めを変えても、最後を同じ拍に着ける。速さより違いを聴く。

**声を出さない課題：** 手拍子の代わりに指で拍を刻み、気になった語の始まりと終わりを記録する。

**回答例：**「入りを遅く感じたが、語尾まで一律に遅れているとは限らなかった。」確認した場面を添える。

### Lesson 03｜呼びかけが歌を動かす

**リード：** ソウルを、声と声の関係から聴く。

**導入本文：** ゴスペルやR&Bの文脈をたどるとき、声の迫力だけに注目すると見落とすものがある。主役の呼びかけに別の声が答える。短い言葉を繰り返し、伴奏も熱を増していく。歌は一人の表現であると同時に、応答を生む行為でもある。

Ray Charles、Aretha Franklin、Otis Reddingの候補曲では、リード、応答、伴奏の三者を追う。歴史的な影響関係は資料で確かめ、似て聞こえるというだけで系譜を結ばない。

**到達点：** コール＆レスポンスを具体的な役割として説明する。

**問い：** 主役が歌わない瞬間にも、曲の勢いは続いている？

**任意の実験：** 一つの短い言葉を録り、それに答える別の言葉を録る。自作の言葉を使い、原曲の叫びは再現しない。

**声を出さない課題：** リード／コーラス／楽器の受け渡しを三色でメモする。

**回答例：**「主役の語尾の後ろに別の声が入り、区切りが次の始まりにもなっている。」当てはまる箇所を探す。

### Lesson 04｜声をリズム楽器として聴く

**リード：** 子音と休符にも、グルーヴがある。

**導入本文：** 歌のリズムは、音符の数だけでは決まらない。短く切る音、長く保つ母音、次の言葉までの空白。それぞれがドラムやベースと関係を作っている。旋律を追う耳を少し休ませて、声の輪郭だけを聴いてみよう。

James Brown、Stevie Wonder、Michael Jacksonを比較する。三人を同じ「ファンクの歌い方」にまとめず、短い音と言葉のつながり方を観察する。

**到達点：** 伴奏の反復と声のリズムの違いを一つ見つける。

**問い：** 声が止まったあと、何が拍を運んでいる？

**任意の実験：** 自作の一文を、同じテンポで「語尾を短く／長く」の二通り録る。

**声を出さない課題：** 声のある場所だけ16分グリッドに印を付ける。正確な採譜でなく概略でよい。

**回答例：**「長く伸ばす版では、次の音までの空白が減った。短く切る版では伴奏が見えやすくなった。」自分の実験結果として書く。

### Lesson 05｜親密さと強弱

**リード：** 声が近く感じる理由を探す。

**導入本文：** 親密さは小声だけで作られるものではない。言葉のまとまり、音の始まり、フレーズの途中で引く動き、周囲の声の重なり方。聴き手との距離を感じさせる要素を、一つずつ見ていこう。

Marvin Gaye、Al Green、Donny Hathawayを聴き、主声の変化と録音上の広がりを区別する。息の成分が聞こえることを、そのまま「大量に息を漏らす発声」の指示に置き換えない。

**到達点：** 親密という印象を二つの観察に分解する。

**問い：** 声量以外で、距離を近く感じさせたものは？

**任意の実験：** 普段の声で短い一文を録り、語の区切りだけを変える。ささやき続ける練習は行わない。

**声を出さない課題：** 主声の近さと周囲の空間の広さを、別々の言葉で書く。

**回答例：**「伴奏は広く感じるが、主声は手前に聞こえる。声の小ささだけでは説明できない。」

### Lesson 06｜装飾と着地点

**リード：** 細かな音を、行き先から聴く。

**導入本文：** 一つの母音にいくつもの音を載せるメリスマ。まず注目したいのは、数の多さより始まりと終わりだ。短い装飾が言葉を引き延ばし、拍の着地点が次のフレーズを準備する。途中の音を全部採る前に、どこからどこへ向かったかを追おう。

Chaka Khan、Whitney Houston、Mariah Careyを聴く。装飾、強弱、曲全体の盛り上がりを別々に捉える。高音や大声の再現は課題にしない。

**到達点：** 装飾の出発・途中・着地を区別する。

**問い：** 途中の音を省いても、フレーズの向かう先は残る？

**任意の実験：** 出しやすい高さで二つの近い音をゆっくりつなぐ。難しければ発声は省く。

**声を出さない課題：** 装飾の動きを矢印で描き、最後に落ち着く場所へ印を付ける。

**回答例：**「細かな動きより、最後の母音が伴奏のどこに着いたかが印象を決めていた。」

### Lesson 07｜高さと声色を分ける

**リード：** 高い・低いの先にある、質感の変化。

**導入本文：** 音が高くなると、必ず強くなるのだろうか。薄く聞こえる声、厚く聞こえる声、輪郭の変化。高さと質感を別々に記録すると、歌い手が曲の中で選ぶ表情を見つけやすくなる。

Prince、Jeff Buckley、Minnie Ripertonを聴く。「裏声」「ミックス」といった名前を急いで付ける前に、何がどう変わって聞こえたかを書こう。発声機構は録音だけから確定しない。

**到達点：** 高さ、音量、声色を混同しない。

**問い：** 音が上がった場面で、輪郭と強さはどう変わった？

**任意の実験：** 高音を真似せず、自分の普段の声を一度録り、音の始まりと終わりを観察する。

**声を出さない課題：** 高さと声色の変化を二本の線で描く。高い装飾は聴く課題に限定。

**回答例：**「音は上がったが、厚みが増したとは感じなかった。」声の分類名より観察を残す。

### Lesson 08｜大きな歌を分解する

**リード：** ロックの迫力を、声・編曲・録音から見る。

**導入本文：** 迫力のある歌を聴くと、声量に理由を求めたくなる。けれど、コーラスの重なり、ギターとの応答、残響、静かな場面との落差も、大きさの感覚を変える。完成した音から、どの要素が働いているかを考えてみよう。

Queen、Led Zeppelin、Tina Turnerの声を扱う。歪みや叫びを力で模倣する課題は設けず、構成や声の出入りを読む。

**到達点：** 迫力の理由を声以外も含めて説明する。

**問い：** 伴奏や重なる声が減ったら、同じ印象になる？

**任意の実験：** 普段の声を録った同じ素材で、無音の間隔だけを変えて比較する。

**声を出さない課題：** 曲中の密度を「少ない／増える／いっぱい」の三段階で記録する。

**回答例：**「主声の変化だけでなく、入ってくるコーラスと直前の空白も大きさに関わると感じた。」

### Lesson 09｜言葉が場面を作る

**リード：** 歌の中の語り手を聴く。

**導入本文：** 一つの文章でも、区切り方や強調する言葉が変わると、話している相手や場面が違って感じられる。歌ではそこに旋律と伴奏が加わる。今日の焦点は、言葉がどう並び、どこで表情を変えるかだ。

Joni Mitchell、Nina Simone、David Bowieを聴く。曲の語り手、作者、実際の歌手の人生は同一と決めつけない。歌詞の全文や訳文は転載せず、テーマの短い要約と聴く場所で案内する。

**到達点：** 言葉の区切りと曲の展開を結びつける。

**問い：** 同じ言葉が、前後の流れで違って聞こえる場所は？

**任意の実験：** 自作の「今日は、ここまでにしよう」を、区切る場所を変えて話す。

**声を出さない課題：** 歌詞の内容を複写せず、場面の変化を自分の短い言葉で要約する。

**回答例：**「繰り返しが来る直前の間が変わり、同じ言葉を違う距離から聞いたように感じた。」

### Lesson 10｜R&Bの時間感覚

**リード：** 反復の上で、声はどう動く？

**導入本文：** 同じ伴奏が繰り返されると、声の細かな位置が耳に入りやすくなる。入りを待つ、語尾をつなぐ、短く返す。一律に「後ろへずらす」と考える前に、フレーズの中で何が一定で何が動くかを聴こう。

D'Angelo、Erykah Badu、Lauryn Hillを比較する。歌だけの印象と、ドラムやベースと一緒に聞いた印象を両方残す。

**到達点：** 反復と変化の関係からタイミングを説明する。

**問い：** 入りの遅さと語尾の位置は、同じ方向に動いている？

**任意の実験：** 自作の短い文を一定の拍に合わせ、言い始めだけを変えて比べる。

**声を出さない課題：** 繰り返す伴奏の目印を一つ決め、声との位置関係を書き込む。

**回答例：**「フレーズ全部が同じだけずれているのではなく、途中で伴奏との距離が変わると感じた。」

### Lesson 11｜声が重なるとき

**リード：** 主役の後ろにも、歌の設計がある。

**導入本文：** リードのメロディーだけを追っていると、声の配置を見落とす。低い支え、高い返答、同じ言葉を重ねる声、別の旋律で動く声。それぞれが役割を持ち、主役の聞こえ方を変えている。

Earth, Wind & Fire、Boyz II Men、Imogen Heapを比較する。人が重ねた声と電子的な処理は、確認できる制作資料がある場合に区別する。完成音だけで使用機器を決めない。

**到達点：** リードと少なくとも二つの支える役割を区別する。

**問い：** 主声から耳を外すと、どんな動きが続いている？

**任意の実験：** 自作の一音または一文を二回録り、二つを重ねる。コピーした同一波形との違いを聴く。

**声を出さない課題：** 聞こえる声を、位置と役割の図にする。正確な人数は断定しない。

**回答例：**「背後の声はずっと同じ仕事ではなく、支えから応答へ変わった。」

### Lesson 12｜日本語を旋律にする

**リード：** 母音の長さと、言葉の意味のまとまり。

**導入本文：** 普段使う日本語でも、歌になると時間の使い方が変わる。母音を残す、語をまたいでつなぐ、一部分だけ輪郭を立てる。意味が分かるぶん、音としての働きに耳を移すと新しい違いが見つかる。

宇多田ヒカル、椎名林檎、玉置浩二を聴く。三人の「日本語らしさ」を一つの物差しで測らず、言葉と旋律を結びつけるそれぞれの選択を探す。

**到達点：** 母音、子音、言葉の区切りを対象曲の場面で説明する。

**問い：** 意味の区切りと、音の切れ目は同じ場所にある？

**任意の実験：** 自作の「明日は少し遠くへ」を、話す／出しやすい一音で言う、の二通り録る。

**声を出さない課題：** 一つの短い区間で、長く聞こえた母音と休符を印にする。

**回答例：**「言葉としては区切れるところを、母音が次へつないでいるように感じた。」

### Lesson 13｜録音が作る声

**リード：** 声の近さ、広さ、変形を楽しむ。

**導入本文：** 録音された歌には、その場で歌った声に加えて、編集や重ね録り、空間、音の処理が関わる。加工は作品の語り方の一部でもある。何が聞こえるかと、実際にどう作ったかを分けながら聴いてみよう。

Billie Eilish、Bon Iver、Daft Punkを比較する。近い声、重なる声、加工された輪郭を観察し、同じ印象が別の手段でも作れることを考える。

**到達点：** 聞こえる効果と機材名の推定を区別する。

**問い：** 音の処理が変わると、同じ言葉の距離感はどう変わる？

**任意の実験：** 自分の声の短い録音に、手元の録音アプリで使える残響を少し加える。原音と再生音量を合わせて比較する。

**声を出さない課題：** 手持ちの自作音源がなければ、教材曲の声の近さと広がりを言葉にする。配信音源の保存や抽出は不要。

**回答例：**「広がりは増したが、言葉の頭は近く残っている。残響の量だけでなく、その始まりにも注目したい。」

### Lesson 14｜自分の歌の選択肢にする

**リード：** 聴いてきた言葉で、もう一度自由に聴く。

**導入本文：** 最後は説明を先に読む前に、自分の耳で三つの観点を選ぼう。声の入り、語尾、伴奏との関係。これまでの曲と似た働きも、まだ名前を付けられない魅力も見つかるはずだ。

山下達郎、MISIA、Adoを入口に、一番気になった曲を選ぶ。Adoの歪みや強い発声は聴く課題にとどめる。持ち帰るのは、本人と同じ声になる方法ではなく、自分ならどの表現を選ぶかという判断だ。

**到達点：** 根拠のある観察を三つ書き、次に試す一つを選ぶ。

**問い：** どの表現を、自分の歌や次の鑑賞に持ち帰りたい？

**任意の実験：** これまでの自作素材で一つの条件だけ変え、二つの録音を比較する。歌わず、聴く観点だけ選んでも完了。

**声を出さない課題：** 未習の一曲を選び、三つの観察と一つの疑問を書く。

**回答例：**「次は語尾の長さを変えたい。理由は、伴奏に場所を渡す瞬間が、自分の好きな曲に共通していたから。」

## 5. 代表3曲の詳細原稿

以下は曲カードを実装できる粒度の原稿。録音に関する事実は出典、分析は観察の提案として記載する。公開前に対象Spotify版との対応と観察箇所を実聴確認する。

### rec-001｜Sam Cooke — You Send Me

**一文：** 滑らかさを、音の始まりと語尾から聴いてみる。

**背景：** Sam Cookeはゴスペル・グループSoul Stirrersでの活動を経て、ポップの領域へ進んだ歌手・ソングライターです。「You Send Me」は1957年にKeenから発表された代表的な録音です。歌手としての魅力だけでなく、作品を生み出す側としての活動も、人物ページでたどります。[S4][S7]

**聴く前の地図：** 最初から「柔らかな声」とまとめず、音が始まる瞬間、母音が続く時間、語尾がほどける瞬間の三つに分けます。滑らかさを感じたら、その印象を作っていたのが音のつながりなのか、強弱なのか、伴奏との関係なのかを探してみましょう。

**三つの聴き方：**

1. 最初の歌の一区切りを聴き、声を追わずに全体の距離感を感じる。
2. 同じ区間で、長く続く母音の始まりと終わりだけを追う。高さがすぐ定まるか、動きながら落ち着くかにも耳を向ける。
3. 伴奏に戻り、声が伸びている間と声が消えた後に、ほかの音が何をしているかを聴く。

**短い実験：** 自分で作った「今日はここにいる」を、出しやすい高さの一音で短く言う。最後をすっと切る版と、少し残す版を作り、同程度の再生音量で聴き比べる。原曲の旋律や声質を再現する課題ではありません。

**声を出さない場合：** 紙にフレーズ一本の線を描き、終わりを角／なだらかな線で表す。

**雑に覚えない：** 柔らかく聞こえる声を、息を大量に漏らすことと結びつけない。完成音には歌い方だけでなく録音も関わります。

**メモの問い：**「柔らかい」と感じた場所を、一つの動詞で説明すると？

### rec-012｜Michael Jackson — Rock With You

**一文：** 流れるメロディーの中に、短いリズムの輪郭を探す。

**背景：** 1979年のアルバム『Off the Wall』に収録された曲です。教材ではライブや別ミックスを混ぜず、指定するアルバム版を基準にします。公式カタログでもアルバム収録を確認できます。[S9]

**聴く前の地図：** 母音は旋律を運び、子音は言葉の輪郭を作ります。二つを分けて聴くと、滑らかなフレーズの中にも短い出来事が見つかります。声の高さを追う耳と、ドラムのように音の入りを追う耳を切り替えてみましょう。

**三つの聴き方：**

1. 最初のヴァースから最初のサビまでを一度聴き、伴奏の反復をつかむ。
2. その中の一つの短いフレーズに絞り、言葉が始まる瞬間と、母音が続く時間を分けて追う。
3. 同じフレーズを伴奏ごと聴き、声が止まったあとに残るリズムを探す。

**短い実験：** 原曲と無関係な自作の「まだまだ先へ」を一定の拍で言い、語尾を短くする版／長くする版を比べます。無理に息を足したり、本人の声の細さを作ったりする必要はありません。

**声を出さない場合：** 画面のグリッドに、子音の入りと語尾が終わる位置を別の印で置く。原曲の採譜として正誤を判定しません。

**雑に覚えない：** 歌手の特徴を、一つの息の音や掛け声だけで代表させない。繰り返す伴奏との関係も含めて聴く。

**メモの問い：** 滑らかさを感じたのは母音、リズムを感じたのは子音だった？ 反対の場所もあった？

### rec-034｜宇多田ヒカル — First Love

**一文：** 日本語の母音が、どこまで旋律を運ぶか。

**背景：** 1999年のアルバム『First Love』の表題曲を扱います。公式の15周年盤にはリマスター音源やライブ映像が含まれるため、教材が指定する演奏と収録年・再発年を分けて確認します。[S8][S10]

**聴く前の地図：** 意味を追える言葉ほど、音の細かな変化は通り過ぎてしまいます。今日は一つの短い区間を選び、どの母音が残り、どこで次の言葉が始まるかに注目します。意味の切れ目と音の切れ目は、同じでしょうか。

**三つの聴き方：**

1. 最初のヴァースの一区切りを聴き、言葉の意味のまとまりを自分の言葉で要約する。
2. 同じ区間で、長く聞こえる母音と短く切れる語尾を一つずつ探す。
3. 伴奏と一緒に聴き、声が消えたところで何が続きを受け持つかを考える。

**短い実験：** 自作の「明日は少し遠くへ」を普段の声で話し、次に楽な一音に乗せて言います。どちらで言葉の区切りが変わったかを比べます。原曲の高さや節回しは使いません。

**声を出さない場合：** 意味のまとまりを四角、長い母音を線、休符を空白で描く。歌詞を書き写す必要はありません。

**雑に覚えない：** 語尾の揺れや音色から、特定の喉の使い方を断定しない。日本語の歌い方を一つの正解に固定しない。

**メモの問い：** 言葉の意味を強く受け取った場所と、音として惹かれた場所は同じだった？

## 8. 声と録音の実験室 — 8本の原稿骨子

ここでの操作例は教材用の提案。対象歌手の実際の設定を再現したものではない。スマホだけでできる「聴く・比べる」と、外部マイクやDAWがある場合の「機材で試す」を分ける。

### 01｜マイクとの距離を変える

同じ短い自作素材を、同じマイクに対して近い位置と少し離れた位置で録る。距離以外の条件をできるだけそろえ、後から再生音量を合わせて比較しよう。指向性マイクでは距離が低域の聞こえ方にも影響する場合がある。スマホは自動処理が入ることもあるので、その結果をすべて発声の変化と考えない。[S2]

**観察：** 言葉の輪郭／低い成分／周囲の音。**初期値例：** 外部マイクで10cmと20cm。機種の推奨範囲で調整し、ライブ時の万能な距離としては扱わない。

### 02｜入力の余裕と、聞き取りやすいモニター

入力ゲインとヘッドホン音量を別々に扱おう。大きく聞こえないからといって入力を上げ続けると、録音が割れることがある。まず短い素材でクリップ表示を確認する。自分の声が聞こえにくい場合も、無理に声を張る前に伴奏とのバランスを調整する。

**観察：** 録音の歪み／伴奏に埋もれる言葉。**設定値：** 万能なピーク値は指定せず、使用機材のメーターと取扱説明に合わせる。

### 03｜EQは、何を前に出す？

同じ録音で一つの帯域だけを少し変え、音量を合わせて戻してみる。変えた直後の派手さではなく、言葉が聴き取りやすくなったか、ほかの楽器と共存するかを判断する。声の太さを削りすぎたら元へ戻そう。

**実験初期値：** 広い範囲を±2dB程度。周波数は対象素材に合わせて選ぶ。低域を一律に削るテンプレートは作らない。機能の読み方は使用DAWの公式資料で確認する。[S3]

### 04｜コンプと音量調整

コンプレッサーは設定した条件に応じて音量変化を抑える処理。短い声の頭と長い母音で効き方が違うかを聴こう。音量を手で整える操作との役割の違いも試す。[S3]

**実験初期値：** Ratio 2:1、強い箇所で1〜3dB程度のゲインリダクションを起点にする。Attack／Releaseは機種の穏やかなプリセットを基準とし、声の頭と語尾を聴いて一つずつ変える。これは編集者が提案する比較条件で、原曲の設定ではない。

### 05｜歯擦音を残す・抑える

子音は言葉を伝える一部だが、録音で一部が強く目立つ場合もある。歯擦音を扱う処理を使うときは、全体を鈍くしていないかを元音と比べよう。周波数や効き具合は声・マイク・処理方式で変わる。

**実験：** 機材のDe-esserを最小限から加え、同じ子音とそれ以外の母音を交互に聴く。具体操作は選んだ機材の公式マニュアルに対応させる。未調査の機種の操作手順は公開しない。

### 06｜残響の長さと始まるタイミング

残響が多いことと、声が遠いことを分けて考えよう。元の声が止まったあとの尾、言葉の頭の見え方に注目して比較する。プリディレイは直接音から残響が始まるまでの時間を扱うパラメータ。[S2]

**実験初期値：** 同じ短いリバーブでプリディレイ0ms／30msを比較する。次に長さだけ変える。最適値ではなく違いを聴くための条件で、原曲への処方ではない。

### 07｜ダブルとハーモニー

自作の短いフレーズを二回録り、二つを重ねてみよう。同じ波形を複製する場合との違いを聴き、別テイクの細かな差がどう聞こえるかを確認する。ダブル、別旋律のハーモニー、左右への配置は別の操作として試す。

**観察：** 一人らしさ／広がり／言葉の明瞭さ。**発展：** モノで聴き、広がりを減らしたときに何が残るか比較する。

### 08｜声を素材として加工する

音の高さを扱う処理、声の輪郭を変える処理、別の音を声の動きで形づくる処理は、同じ「加工」でも異なる。まず一つずつ聴こう。機材の名称から録音の作り方を逆算せず、確認できる資料と自分の実験を分ける。[S3]

**観察：** 言葉の明瞭さ／高さ／質感。**発展候補：** Pitch correction、Formant、Vocoder、Harmony。操作は対応機材を決めてから追記する。

## 9. 基礎と用語 — 掲載初稿

| 用語 | 本文 |
|---|---|
| ピッチ | 音の高さ。装飾や揺れを含めて、どこへ向かうかも聴こう。 |
| リズム | 音が始まり、続き、止まる時間の関係。 |
| フレーズ | 音や言葉が一まとまりとして感じられる単位。 |
| アタック | 音の始まりの輪郭。硬い、丸いなどの印象を具体的な場面で確かめよう。 |
| リリース | この教材では声を終える瞬間の扱い。コンプのReleaseとは文脈が異なる。 |
| 母音／子音 | 言葉を作る音の種類。歌では母音の持続と子音の位置を分けて聴ける。 |
| アクセント | 音量だけでなく長さや高さなどによって目立つ部分。 |
| シンコペーション | 拍の強弱の予想をずらすようなリズムの働き。 |
| バックビート | 一般的な4拍子では主に2拍目と4拍目の強調。 |
| レイドバック | 拍に対して後ろ寄りに感じる時間の扱い。何を基準に感じたかも記録する。 |
| 音価 | 音の長さ。歌では母音の持続と語尾の終わりを確認しよう。 |
| メリスマ | 一つの音節に複数の音高を置く歌い方。 |
| ビブラート | 音の高さなどが周期的に揺れて聞こえる表現。速さや現れる場所を観察する。 |
| ポルタメント | ある高さから別の高さへ、連続的につないで聞かせる表現。 |
| 声区・レジスター | 声の出方を整理する概念。教材では用語だけで本人の身体動作を決めない。 |
| ファルセット | 高めの軽い声などを指して使われる用語。流派や文脈の用法を確認する。 |
| ミックスボイス | 指導法によって意味や説明が異なる言葉。単一の身体操作として説明しない。 |
| ベルト | 主に強く明瞭な歌唱表現を指す用語。教材では独学で押し出す手順に置き換えない。 |
| コール＆レスポンス | 呼びかけと応答。声同士でも、声と楽器の間でも起こる。 |
| ダブル | 同じパートを別テイクなどで重ねる制作手法。 |
| ハーモニー | 複数の音の関係。コーラスでは主旋律と別の音をどう重ねるかを見る。 |
| EQ | 周波数ごとの音量バランスを調整する処理。 |
| コンプレッサー | 設定条件に応じて音量変化を抑える処理。 |
| リバーブ／ディレイ | 音の残響を作る処理／遅れてくる音を作る処理。 |
| フォルマント | 声の共鳴に関係するスペクトル上の特徴。ピッチと同じ意味ではない。 |

用語は学習用の最小定義。声区・発声機構の詳細説明を増補するときは、音声科学の一次資料または専門家レビューを追加し、流派固有語との境界を明記する。

## 11. 本文を全曲へ広げるための執筆仕様

- 曲ごとに背景100〜180字、観察解説180〜300字、三つの聴き方、任意課題80〜160字、無発声代替、混同しやすい点、振り返りの問いを用意する。
- 同じ歌手の別曲で文章を使い回さず、対象場面と教育目的を変える。
- 先に正解を言い切らず、聴いて確かめられる言葉を使う。完成稿では実聴レビューした区間と確認日を内部記録する。
- 年代、クレジット、機材、制作技法の事実は主張単位で出典を紐づける。出典のない事実は断定しない。
- 歌詞の全文、全文訳、原曲の採譜、無許諾の音源や画像を教材に収録しない。課題は自作の短い言葉・旋律で作る。
- 28の基本曲＋14の発展曲を同じ水準で用意する。3曲の例だけで全コース完成と扱わない。
